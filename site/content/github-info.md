## Recent updates worth watching

- **Issue statuses and repository boards (public preview).** Issues can now be marked Backlog, Todo, In progress, In review, Done, Not planned or Duplicate, and linking or readying a pull request updates the status automatically. This gives your team a clearer view of work in flight. Source: [GitHub Changelog, Nov 23, 2026](https://github.blog/changelog/2026-11-23-issue-statuses-and-repository-boards-are-in-public-preview).
- **Clearer pull request overview (public preview).** Failed optional checks no longer make a mergeable pull request look blocked, and missing requirements are easier to spot, so reviewers can see what to do next. Source: [GitHub Changelog, Nov 19, 2026](https://github.blog/changelog/2026-11-19-improvements-on-the-pull-request-overview-in-public-preview).
- **Agent skills.** A skill is a versioned directory built around a `SKILL.md` file that captures a repeatable task so you and your agents can reuse it. Tools and permissions still come from the host that runs it. Source: [GitHub Blog, Nov 12, 2026](https://github.blog/ai-and-ml/github-copilot/build-once-run-on-any-agent-a-practical-guide-to-agent-skills/).
- **Example agentic workflows.** Browse ready-made workflows, such as a daily issues report and stale-repository checks, as starting points for repository automation. Source: [Awesome Copilot workflows](https://awesome-copilot.github.com/workflows/).
